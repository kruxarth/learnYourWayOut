02 · PROPOSED SOLUTION

The maze is the quiz

Most learning games pause the fun for a quiz popup. Here, every answer is a place you run to.

  • Answer with your feet5 room types turn every question type into movement.
  • Wrong turns teachA detour shows the answer, why, a worked example, a retry.
  • Adapts to every playerHarder after 2 right, easier after a miss; replay weak spots.
  • AI custom questionsType a topic or paste notes; DeepSeek builds a live pack.
  • Live multiplayer racesRace friends through the same seeded maze as ghost beans.
  • A new maze every runSeeded mazes with forks, dead ends, coins and rising slime.
USP Answers are places, not buttons. Mistakes become lessons, not game-overs.

UI React DOM + zustand: HUD, menus, results
Render three.js + React Three Fiber
Engine TypeScript, fixed 120 Hz step, own collision
Content JSON packs + validator, QuestionSource
AI QUESTIONS

Node proxy → DeepSeek API; the key stays on the server.

MULTIPLAYER

WebSocket relay: shared seed + positions 10 times a second.

  • Maze: DFS backtracker + braiding on a seeded PRNG: one seed, one identical maze.

  • Adaptive picker: tier staircase, scored by recency and weak concepts.

  • AI pipeline: JSON schema → validator → cached pack; built-in bank fallback.

  • Multiplayer: share the seed, stream positions; each client runs its own course.

  • Test plan: a headless bot plays every generated course before release.
